Use the Mailchimp Marketing API to programmatically create and send email campaigns to your audience.

## Create a campaign

Create a new regular campaign associated with an audience:

```bash
curl -X POST "https://us1.api.mailchimp.com/3.0/campaigns" \
  --user "anystring:YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "regular",
    "recipients": {
      "list_id": "YOUR_LIST_ID"
    },
    "settings": {
      "subject_line": "Welcome to our newsletter",
      "from_name": "Acme Corp",
      "reply_to": "hello@example.com"
    }
  }'
```

## Set the campaign content

Add HTML content to your campaign:

```bash
curl -X PUT "https://us1.api.mailchimp.com/3.0/campaigns/{campaign_id}/content" \
  --user "anystring:YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "html": "<html><body><h1>Hello!</h1><p>Welcome to our newsletter.</p></body></html>"
  }'
```

## Send the campaign

Once your campaign is configured, send it:

```bash
curl -X POST "https://us1.api.mailchimp.com/3.0/campaigns/{campaign_id}/actions/send" \
  --user "anystring:YOUR_API_KEY"
```

<Warning>
Sending a campaign is irreversible. Use the `/actions/test` endpoint to send a test email first.
</Warning>

## Send a test email

Before sending to your full audience, send a test:

```bash
curl -X POST "https://us1.api.mailchimp.com/3.0/campaigns/{campaign_id}/actions/test" \
  --user "anystring:YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "test_emails": ["test@example.com"],
    "send_type": "html"
  }'
```

## Check campaign status

After sending, retrieve the campaign report:

```bash
curl -X GET "https://us1.api.mailchimp.com/3.0/reports/{campaign_id}" \
  --user "anystring:YOUR_API_KEY"
```

The response includes open rates, click rates, bounces, and other performance metrics.
