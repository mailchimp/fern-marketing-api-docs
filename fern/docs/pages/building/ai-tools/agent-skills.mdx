Even the best-designed platforms have idiosyncrasies, and Mailchimp is no
exception. Your agent is a capable coder and our docs give it plenty of
context, but a skill teaches it how to handle those quirks in advance, so it
writes code like a seasoned Mailchimp integration developer instead of
discovering the gotchas the hard way.

Each skill is a single set of instructions your agent loads when it recognizes
you're working on a relevant task. It reads the description, decides the skill
applies to what you asked, and pulls in the full instructions before it starts.
Once installed, a skill stays available in every new conversation, so you are
not pasting the same guidance in each time.

Mailchimp publishes skills for the parts of the Marketing API where the right
implementation is not the obvious or intuitive one.

For the skill format itself, and the agents that support it, see
[Agent Skills](https://agentskills.io).

## Available skills

| Skill | Use it when |
|---|---|
| `set-consent-correctly` | Adding or updating contacts from a signup form, checkout, or CRM sync, and the write has to record what the person chose without overwriting consent they already gave. |
| `set-up-oauth` | Implementing OAuth 2 to connect other people's Mailchimp accounts: the authorize redirect, the callback and code exchange, and token storage per account. |
| `subscribe-to-webhooks` | Creating a webhook, verifying delivery signatures, and keeping a handler that survives duplicate deliveries without echoing its own writes back into the audience. |
| `run-bulk-jobs` | A job is too large for one request, and you need to choose between the bulk endpoints, poll a batch without hitting the connection limit, and tell a partial failure from a success. |

Each skill links to the concept pages behind it, so an agent that needs the
full mechanism can follow the reference rather than work from the summary.

## Install them

Point the installer at the docs site and pick what you want from the list it
shows you:

```bash
npx skills add https://preview.developer.mailchimp.com
```

We recommend installing all skills as a first step whenever you code against the
Marketing API with an AI agent. Installing a skill is free, and having it
installed pays off when your agent needs it.

Claude Code, Cursor, and the other agents that support the format read them
from the directory the command writes to.

Each skill is a single `SKILL.md` file with no bundled scripts or reference
files, so you can also read one before installing it, or save it straight into
the directory your agent loads skills from:

```bash
curl https://preview.developer.mailchimp.com/.well-known/agent-skills/set-up-oauth/SKILL.md
```
