---
title: Generate your API key
description: Create an API key in your Mailchimp account and store it securely.
---

An API key authenticates requests against your own Mailchimp account. Here's how
to create one:

1. Navigate to the [API Keys section](https://us1.admin.mailchimp.com/account/api/) of your Mailchimp account.
2. Click **Create New Key** and give it a descriptive name that tells you which application it's used for.
3. Copy the generated key immediately and store it in a secure location. You won't be able to see or copy the key once you finish generating it.

Your server prefix is the first part of the URL you see when logged in; if it's
`https://us19.admin.mailchimp.com/`, your prefix is `us19`. It's also appended
to the key itself after a hyphen. You'll need both values to make a request.

<Note>
**Note**: An API key grants full access to your account. Keep it as secure as
you would a password, and don't use one in a browser or a mobile app; see
[API keys](/marketing/api-concepts/authentication/api-keys) for why.
</Note>
