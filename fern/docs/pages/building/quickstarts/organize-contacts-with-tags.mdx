## At a glance

[Tags](https://mailchimp.com/help/getting-started-tags/) are labels that help organize your contacts. While [segments](https://mailchimp.com/help/getting-started-with-segments/) help filter an audience based on things like when a contact subscribed or how often they engage with campaigns, you can use tags to bring your own email targeting and organization strategy into Mailchimp.

You could use tags to:

- Structure campaigns for specific audiences, tagging contacts with terms like “Holiday Send” or “Influencer”
- Directly map tags from your CRM onto tags in your Mailchimp audience
- Translate behaviors—for example, a contact who’s spent $1,000 in your store—into tags that can be used in future campaigns

In this guide, we’re going to create a new “Influencer” tag to track and target our most influential customers. We’ll walk through how to programmatically tag contacts as influencers, view all of our influencers, remove the influencer tag from a contact whose sway has (sadly) diminished, and continue to manage tags through all of our potential use cases.

## What you’ll need

- [An audience](https://mailchimp.com/help/create-audience/) in your Mailchimp account
- The [Audience/List ID](https://mailchimp.com/help/find-audience-id/) for that audience
- Your [API key](/marketing/build/get-started/generate-your-api-key)

## Label a contact with a tag

We want to tag Urist McVankab, whose star has been rising recently, as an influencer. 

To add the Influencer tag, make this request using your List ID and [the MD5 hash](/marketing/api-concepts/methods-and-parameters/#path-parameters) of Urist McVankab’s email address:

<CodeBlocks>
```bash title="cURL"
apikey="YOUR_API_KEY"
listid="YOUR_LIST_ID"
subscriber_email="urist.mcvankab@example.com"
subscriber_hash="$(echo -n "$subscriber_email" | md5sum | cut -d’ ‘ -f1)"
# use below for OS X
# subscriber_hash="$(md5 -s "$subscriber_email" | cut -d' ' -f4)"

curl -s --request POST \
--url "https://api.mailchimp.com/3.0/lists/${listid}/members/${subscriber_hash}/tags" \
--user "foo:${apikey}" --include \
--data '{"tags": [{"name": "Influencer", "status": "active"}]}'
```

```typescript title="TypeScript"
import { MailchimpClient } from "@mailchimp/mailchimp-marketing";
import crypto from "crypto";

const client = new MailchimpClient({
  token: "YOUR_API_KEY",
});

const email = "urist.mcvankab@example.com";
const listId = "YOUR_LIST_ID";
const subscriberHash = crypto
  .createHash("md5")
  .update(email.toLowerCase())
  .digest("hex");

const response = await client.lists.createMemberTag({
  list_id: listId,
  subscriber_hash: subscriberHash,
  tags: [
    {
      name: "Influencer",
      status: "active",
    },
  ],
});

console.log(
  `The return type for this endpoint is null, so this should be true: ${
    response === null
  }`
);
```

```go title="Go"
	},
```

```java title="Java"

import com.mailchimp.marketing.resources.lists.types.CreateMemberTagListsRequestTagsItem;
import com.mailchimp.marketing.resources.lists.types.CreateMemberTagListsRequestTagsItemStatus;
import java.security.MessageDigest;
import java.math.BigInteger;

MailchimpClient client = MailchimpClient.builder()
    .token("YOUR_API_KEY")
    .build();

String listId = "YOUR_LIST_ID";

MessageDigest md = MessageDigest.getInstance("MD5");

String subscriberHash = String.format("%032x", new BigInteger(1, digest));

client.lists().createMemberTag(
    listId,
    subscriberHash,
    CreateMemberTagListsRequest.builder()
        .tags(List.of(
            CreateMemberTagListsRequestTagsItem.builder()
                .name("Influencer")
                .status(CreateMemberTagListsRequestTagsItemStatus.ACTIVE)
                .build()))
        .build()
);
System.out.println("Request completed with no exception thrown.");
```

</Note>

## View a contact’s tags

Now we want to check out all of Urist’s tags. Again, using [the MD5 hash](/marketing/api-concepts/methods-and-parameters/#path-parameters) of his email address, make the following request: 

<CodeBlocks>
```bash title="cURL"
apikey=”YOUR_API_KEY”
listid=”YOUR_LIST_ID”
subscriber_email=”urist.mcvankab@example.com”
subscriber_hash=”$(echo -n “$subscriber_email” | md5sum | cut -d’ ‘ -f1)”
# use below for OS X
# subscriber_hash="$(md5 -s "$subscriber_email" | cut -d' ' -f4)"

curl -s --request GET \
--url "https://api.mailchimp.com/3.0/lists/${listid}/members/${subscriber_hash}/tags" \
--user "foo:${apikey}" | jq -r .
```

## Remove a tag

Time passes; influence fades. We’ve decided to remove Urist’s Influencer tag. Doing so is simple: make the same request you did when you added the tag, but this time, set the status to `inactive`.

<CodeBlocks>
```bash title="cURL"
apikey=”YOUR_API_KEY”
listid=”YOUR_LIST_ID”
subscriber_email=”urist.mcvankab@example.com”
subscriber_hash=”$(echo -n “$subscriber_email” | md5sum | cut -d’ ‘ -f1)”

# subscriber_hash="$(md5 -s "$subscriber_email" | cut -d' ' -f4)"

curl -s --request POST \
--url "https://api.mailchimp.com/3.0/lists/${listid}/members/${subscriber_hash}/tags" \
--user "foo:${apikey}" --include \
--data '{"tags": [{"name": "Influencer", "status": "inactive"}]}'
```

## Bulk tagging

Forget about Urist—now we have a batch of influencers to tag. 

We can bulk tag contacts in two ways. First, if you’re using a tag that already exists, you’ll need the Tag ID for that tag. When we viewed Urist’s tags above, we saw that the ID for the Influencer tag was `10297`, so we can use that to make the following request:

<CodeBlocks>
```bash title="cURL"
apikey=”YOUR_API_KEY”
listid=”YOUR_LIST_ID”
tagid=”YOUR_TAG_ID”

body() {
  cat <<EOT
{
  “members_to_add”: [
    "dolly.parton@example.com",
    "rihanna@example.com"
  ]
}
EOT
}

count=”$(curl -s --request POST \
--url "https://api.mailchimp.com/3.0/lists/${listid}/segments/${tagid}" \
--user "foo:${apikey}" --include \
--data “$(body)” | jq -r ‘.total_added’)”

echo “Successfully tagged ${count} contacts”
```

The data for our tag includes a `name` (“Influencer”) and the `static_segment` array. If we only wanted to create a tag but add no contacts to it, we could have passed an empty array. For more details, see the [Add segment](/marketing/api/lists/create-segment) endpoint.

<Note>
**Note**: You may have noticed that the API call above references `segments`, but this guide is about tags. This is an implementation detail within the API that can be confusing. Previously tags were referred to as “static segments;” now they are referred to as tags. When you create a tag using the structure above, you’ll see the results as tags and not segments when you view your lists in your Mailchimp account.
</Note>
