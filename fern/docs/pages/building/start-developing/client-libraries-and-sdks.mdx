      <h2 class="mc-tools-heading">Official client libraries</h2>
      <p class="mc-tools-intro">Client libraries wrap the Marketing API in the idioms of your language, so you can work with audiences, campaigns, and reports without hand-rolling requests. Each is generated from the same specification as the <a href="/marketing/api">API reference</a>, so every endpoint is covered. Pick a language for installation and examples on GitHub.</p>

      <h2 class="mc-tools-heading">Mobile SDK</h2>
      <p class="mc-tools-intro">The Mailchimp Mobile SDK implements a mobile-oriented subset of the Marketing API for iOS and Android, so your app can add contacts to an audience, update them, and log in-app events. See the <a href="/marketing/build/start-developing/mobile-sdk">Mobile SDK documentation</a> for installation, initialization, and reference.</p>
