## Install the client library for your language

You can make calls to the Marketing API with whichever method you usually use to make HTTP requests, but Mailchimp offers [client libraries](/tools) that make interacting with the API even simpler. 

To install the client library for your preferred language:

<CodeBlocks>
```bash title="cURL"
# No client installation necessary; just using curl
```

```javascript title="Node"
yarn add @mailchimp/mailchimp_marketing
# OR
npm install @mailchimp/mailchimp_marketing
```

```php title="PHP"
composer require mailchimp/marketing
```

```ruby title="Ruby"
gem install MailchimpMarketing
```

```python title="Python"
pip install mailchimp-marketing
```
</CodeBlocks>
