The Mailchimp Marketing API uses offset-based pagination for endpoints that return collections of resources. This allows you to retrieve data in manageable chunks.

## How pagination works

Most list endpoints accept two query parameters to control pagination:

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `count` | integer | 10 | The number of records to return, up to a maximum of 1000 |
| `offset` | integer | 0 | The number of records to skip from the beginning of the result set |

## Basic usage

Retrieve the first 10 records (default):

```bash
curl -X GET "https://us1.api.mailchimp.com/3.0/lists" \
  --user "anystring:YOUR_API_KEY"
```

Retrieve records 11 through 20:

```bash
curl -X GET "https://us1.api.mailchimp.com/3.0/lists?offset=10&count=10" \
  --user "anystring:YOUR_API_KEY"
```

## Response metadata

Paginated responses include a `total_items` field indicating the total number of available records:

```json
{
  "lists": [...],
  "total_items": 42,
  "_links": [...]
}
```

Use `total_items` along with `count` and `offset` to determine how many pages of results exist.

## Iterating through all results

To retrieve all records from a paginated endpoint:

<CodeBlocks>
```javascript title="JavaScript"
const mailchimp = require("@mailchimp/mailchimp_marketing");

mailchimp.setConfig({
  apiKey: "YOUR_API_KEY",
  server: "us1",
});

async function getAllLists() {
  const allLists = [];
  let offset = 0;
  const count = 100;

  while (true) {
    const response = await mailchimp.lists.getAllLists({
      count: count,
      offset: offset,
    });

    allLists.push(...response.lists);

    if (allLists.length >= response.total_items) {
      break;
    }
    offset += count;
  }

  return allLists;
}
```

```php title="PHP"
$mailchimp = new MailchimpMarketing\ApiClient();
$mailchimp->setConfig([
    'apiKey' => 'YOUR_API_KEY',
    'server' => 'us1',
]);

$allLists = [];
$offset = 0;
$count = 100;

do {
    $response = $mailchimp->lists->getAllLists($count, $offset);
    $allLists = array_merge($allLists, $response->lists);
    $offset += $count;
} while (count($allLists) < $response->total_items);
```
</CodeBlocks>

## Filtering results

Many list endpoints support the `fields` and `exclude_fields` parameters to reduce the response payload. Combine these with pagination for optimal performance:

```bash
curl -X GET "https://us1.api.mailchimp.com/3.0/lists?count=50&offset=0&fields=lists.id,lists.name,total_items" \
  --user "anystring:YOUR_API_KEY"
```

<Note>
The maximum value for `count` is 1000. If you need to retrieve more records, use multiple requests with increasing `offset` values.
</Note>
