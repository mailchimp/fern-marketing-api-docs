# Webhooks

Use webhooks to receive real-time notifications about message events like sends, opens, clicks, bounces, and spam complaints.

## Configure a Webhook

1. Go to **Settings > Webhooks** in your Transactional dashboard.
2. Add a webhook URL that accepts POST requests.
3. Select the events you want to receive.

Mailchimp Transactional will send a JSON payload to your URL for each event.
