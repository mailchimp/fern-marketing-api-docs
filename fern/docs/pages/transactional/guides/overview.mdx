# Overview

Mailchimp Transactional lets you send targeted and event-driven messages to anyone, fast—with best-in-class deliverability.

## What is Mailchimp Transactional?

Mailchimp Transactional (formerly Mandrill) is a reliable, scalable, and secure delivery API for transactional emails from websites and applications.

Use Mailchimp Transactional to send personalized, one-to-one emails like password resets, order confirmations, and welcome messages.
