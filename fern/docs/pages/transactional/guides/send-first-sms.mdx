## At a glance

This guide will walk you through the essentials of sending your first SMS message using the Mailchimp Transactional API. We'll cover how to set up your account, obtain a phone number, and use the API to send a text message. This will ensure you have everything configured correctly to start sending transactional SMS messages to your customers.

## What you'll need

- A Standard or higher Mailchimp account with Transactional enabled and SMS credits
- A phone number approved for sending SMS
- [Your API key](/transactional/guides/quick-start/#generate-your-api-key)

## Create an account

If you don't have a Mailchimp Transactional account, you’ll need to [create a Mailchimp account](https://login.mailchimp.com/signup/) and enable Transactional. 

If you have a Mailchimp Standard plan or higher, you can enable Mailchimp Transactional from the [Monthly plans or credits page of your account](https://us1.admin.mailchimp.com/account/billing-plan/). 

You can [submit an SMS marketing application](https://mailchimp.com/help/set-up-your-sms-marketing-program/?_gl=1*1xmgqak*_up*MQ..*_gs*MQ..&gclid=CjwKCAjwlOrFBhBaEiwAw4bYDcxVp4dg6C6GY9QE3I6euXcHFzPIDo3YvAfeRzHZ7LTHhSiGa0F5DRoCg_QQAvD_BwE&gclsrc=aw.ds&gbraid=0AAAAADh1Fp08-HhUOb_Mfg-ZoakwPG80N#Submit_your_SMS_Marketing_application), and purchase SMS credits from the [SMS overview page](https://login.mailchimp.com/?referrer=%2Fsms%2F&_gl=1*1xmgqak*_up*MQ..*_gs*MQ..&gclid=CjwKCAjwlOrFBhBaEiwAw4bYDcxVp4dg6C6GY9QE3I6euXcHFzPIDo3YvAfeRzHZ7LTHhSiGa0F5DRoCg_QQAvD_BwE&gclsrc=aw.ds&gbraid=0AAAAADh1Fp08-HhUOb_Mfg-ZoakwPG80N), the [SMS settings page](https://login.mailchimp.com/?referrer=%2Fsms%2Fsettings%2F&_gl=1*ci3fic*_up*MQ..*_gs*MQ..&gclid=CjwKCAjwlOrFBhBaEiwAw4bYDcxVp4dg6C6GY9QE3I6euXcHFzPIDo3YvAfeRzHZ7LTHhSiGa0F5DRoCg_QQAvD_BwE&gclsrc=aw.ds&gbraid=0AAAAADh1Fp08-HhUOb_Mfg-ZoakwPG80N), or the SMS editor in Mailchimp. Transactional SMS messages may be sent from programs tied to your account.

To find out how to create an API key and make your first API call, see the [Transactional API Quick Start guide](/transactional/guides/quick-start).

## Send your first SMS

With everything set up, we can start sending SMS messages.

Using the [send-sms API endpoint](/transactional/api/messages/send-sms), the minimum **required** fields to make an SMS send are:

- `key` (string): A valid Mailchimp Transactional API key.
- `message` (object): The message body. Must include:
  - `to` (string): Phone number of the recipient. Required format: E.164 (e.g. `+15551234567`).
  - `from` (string): Phone number or sender ID of the approved SMS program. Must be one of: an E.164 phone number, a short code, or an alphanumeric sender string (EU only).
  - `text` (string): The SMS content to send.
  - `consent` (string): Consent type. Accepted values: `onetime`, `recurring`, or `recurring-no-confirm`.

An example SMS send may look like this:

```bash
curl -X POST https://mandrillapp.com/api/1.1/messages/send-sms \
  -H "Content-Type: application/json" \
  -d '{
    "key": "YOUR_API_KEY",
    "message": {
      "sms": {
        "text": "Hello from Mailchimp Transactional SMS! Visit https://example.com for more info.",
        "to": "+15550000000",
        "from": "+15550000001",
        "consent": "onetime",
        "track_clicks": true
      }
    }
  }'
```


For more information about this endpoint and accepted parameters, review the [API reference documentation](/transactional/api/messages/send-sms).
