# Sending Your First Email

This guide walks you through sending your first transactional email using the Mailchimp Transactional API.

## Prerequisites

- A Mailchimp account with Transactional Email enabled
- An API key

## Send a Message

Use the `/messages/send` endpoint to send your first email.

```json
{
  "message": {
    "from_email": "you@example.com",
    "subject": "Hello!",
    "text": "Welcome to Mailchimp Transactional.",
    "to": [{ "email": "recipient@example.com", "type": "to" }]
  }
}
```
