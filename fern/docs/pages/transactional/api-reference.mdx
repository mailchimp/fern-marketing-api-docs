# API Reference

The Mailchimp Transactional API is a JSON-based API. All requests are POST requests and all responses are in JSON.

## Base URL

```
https://mandrillapp.com/api/1.0/
```

## Authentication

Include your API key as the `key` parameter in every request body.

## Full Reference

For the complete API reference, visit the [Mailchimp Transactional API documentation](/transactional/api).
