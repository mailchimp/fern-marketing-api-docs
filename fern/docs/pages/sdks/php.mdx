The official Mailchimp Marketing PHP SDK provides a convenient, typed wrapper for the Mailchimp Marketing API in PHP applications.

## Requirements

- PHP ^8.1
- Composer

## Installation

Install the SDK using Composer:

```bash
composer require mailchimp/marketing-sdk
```

## Configuration

Initialize the client with your API key:

```php
<?php

use Mailchimp\MailchimpClient;

$client = new MailchimpClient(
    token: 'YOUR_API_KEY',
);
```

You can also pass additional options such as a custom base URL:

```php
$client = new MailchimpClient(
    token: 'YOUR_API_KEY',
    options: ['baseUrl' => 'https://usX.api.mailchimp.com'],
);
```

## Usage examples

### Verify your connection

```php
use Mailchimp\MailchimpClient;

$client = new MailchimpClient(token: 'YOUR_API_KEY');

$response = $client->ping->getPing();
echo $response->healthStatus; // "Everything's Chimpy!"
```

### List your audiences

```php
use Mailchimp\MailchimpClient;

$client = new MailchimpClient(token: 'YOUR_API_KEY');

$pager = $client->lists->getLists();

foreach ($pager as $list) {
    echo $list->name . "\n";
}
```

### Add a subscriber to a list

```php
use Mailchimp\MailchimpClient;
use Mailchimp\Lists\Requests\PostListsIdMembersRequest;

$client = new MailchimpClient(token: 'YOUR_API_KEY');

$response = $client->lists->postListsIdMembers('list_id', new PostListsIdMembersRequest([
    'emailAddress' => 'user@example.com',
    'status' => 'subscribed',
    'mergeFields' => [
        'FNAME' => 'John',
        'LNAME' => 'Doe',
    ],
]));

echo $response->id;
```

### Create and send a campaign

```php
use Mailchimp\MailchimpClient;
use Mailchimp\Campaigns\Requests\PostCampaignsRequest;
use Mailchimp\Campaigns\Types\PostCampaignsRequestRecipients;
use Mailchimp\Types\CampaignsSettings;

$client = new MailchimpClient(token: 'YOUR_API_KEY');

$campaign = $client->campaigns->postCampaigns(new PostCampaignsRequest([
    'type' => 'regular',
    'recipients' => new PostCampaignsRequestRecipients([
        'listId' => 'your_list_id',
    ]),
    'settings' => new CampaignsSettings([
        'subjectLine' => 'My Newsletter',
        'fromName' => 'Your Name',
        'replyTo' => 'you@example.com',
    ]),
]));

// Send the campaign
$client->campaigns->postCampaignsIdActionsSend($campaign->id);
```

## Pagination

List endpoints return a `Pager` which automatically handles pagination across multiple HTTP requests:

```php
use Mailchimp\MailchimpClient;

$client = new MailchimpClient(token: 'YOUR_API_KEY');

// Iterate over all items automatically
$items = $client->lists->getLists();

foreach ($items as $item) {
    echo $item->name . "\n";
}
```

## Error handling

The SDK throws typed exceptions for non-2XX API responses:

```php
use Mailchimp\MailchimpClient;
use Mailchimp\Exceptions\MailchimpApiException;
use Mailchimp\Exceptions\MailchimpException;

$client = new MailchimpClient(token: 'YOUR_API_KEY');

try {
    $response = $client->lists->getLists();
} catch (MailchimpApiException $e) {
    echo 'API error: ' . $e->getMessage() . "\n";
    echo 'Status code: ' . $e->getCode() . "\n";
    echo 'Response body: ' . $e->getBody() . "\n";
} catch (MailchimpException $e) {
    echo 'SDK error: ' . $e->getMessage() . "\n";
}
```
