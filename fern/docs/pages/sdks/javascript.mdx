The official Mailchimp Marketing JavaScript SDK provides a convenient wrapper for the Mailchimp Marketing API in Node.js applications.

## Installation

Install the SDK using npm or yarn:

<CodeBlocks>
```bash title="npm"
npm install @mailchimp/mailchimp_marketing
```

```bash title="yarn"
yarn add @mailchimp/mailchimp_marketing
```
</CodeBlocks>

## Configuration

Initialize the client with your API key and server prefix:

```javascript
const mailchimp = require("@mailchimp/mailchimp_marketing");

mailchimp.setConfig({
  apiKey: "YOUR_API_KEY",
  server: "us1",
});
```

For OAuth 2 authentication:

```javascript
mailchimp.setConfig({
  accessToken: "YOUR_ACCESS_TOKEN",
  server: "us1",
});
```

## Usage examples

### Verify your connection

```javascript
async function pingServer() {
  const response = await mailchimp.ping.get();
  console.log(response);
  // { health_status: "Everything's Chimpy!" }
}
```

### List your audiences

```javascript
async function getAudiences() {
  const response = await mailchimp.lists.getAllLists();
  console.log(response.lists);
}
```

### Add a subscriber

```javascript
async function addSubscriber(listId) {
  const response = await mailchimp.lists.addListMember(listId, {
    email_address: "user@example.com",
    status: "subscribed",
    merge_fields: {
      FNAME: "Jane",
      LNAME: "Doe",
    },
  });
  console.log(response.id);
}
```

### Create and send a campaign

```javascript
async function createCampaign(listId) {
  const campaign = await mailchimp.campaigns.create({
    type: "regular",
    recipients: { list_id: listId },
    settings: {
      subject_line: "Your monthly update",
      from_name: "Acme Corp",
      reply_to: "hello@example.com",
    },
  });

  await mailchimp.campaigns.setContent(campaign.id, {
    html: "<html><body><h1>Hello!</h1></body></html>",
  });

  await mailchimp.campaigns.send(campaign.id);
}
```

## Error handling

The SDK throws errors for failed API calls. Wrap calls in try-catch blocks:

```javascript
try {
  const response = await mailchimp.lists.getAllLists();
} catch (error) {
  console.error("Status:", error.status);
  console.error("Detail:", error.response?.body?.detail);
}
```

## TypeScript support

The SDK includes TypeScript type definitions. Import types for better IDE support:

```typescript
import mailchimp from "@mailchimp/mailchimp_marketing";

mailchimp.setConfig({
  apiKey: process.env.MAILCHIMP_API_KEY,
  server: "us1",
});
```
