The Mailchimp Marketing API provides programmatic access to Mailchimp data and functionality, allowing you to build custom features to do things like sync your audience data, manage campaigns, and more.

## Before you begin

To use the Mailchimp Marketing API, you need:

- A [Mailchimp account](https://login.mailchimp.com/signup/)
- An API key or OAuth 2 access token

## Generate an API key

1. Log in to your Mailchimp account.
2. Navigate to **Profile > Extras > API keys**.
3. Click **Create A Key** and give it a descriptive label.
4. Copy your new API key. You won't be able to see it again.

<Warning>
Keep your API key secure. Do not share it in publicly accessible areas such as GitHub or client-side code.
</Warning>

## Make your first API call

Use your API key to call the API root endpoint and verify your credentials:

<CodeBlocks>
```bash title="cURL"
curl -X GET "https://us1.api.mailchimp.com/3.0/" \
  --user "anystring:YOUR_API_KEY"
```

```javascript title="JavaScript"
const mailchimp = require("@mailchimp/mailchimp_marketing");

mailchimp.setConfig({
  apiKey: "YOUR_API_KEY",
  server: "us1",
});

async function callPing() {
  const response = await mailchimp.ping.get();
  console.log(response);
}

callPing();
```

```php title="PHP"
require_once('/path/to/MailchimpMarketing/vendor/autoload.php');

$mailchimp = new MailchimpMarketing\ApiClient();
$mailchimp->setConfig([
    'apiKey' => 'YOUR_API_KEY',
    'server' => 'us1',
]);

$response = $mailchimp->ping->get();
print_r($response);
```
</CodeBlocks>

A successful response returns information about the authenticated account:

```json
{
  "account_id": "abc123",
  "login_id": "user@example.com",
  "account_name": "Your Account",
  "email": "user@example.com",
  ...
}
```

## Determine your server prefix

Your API key includes your server prefix as the last characters after the dash. For example, if your API key is `abc123def456-us6`, your server prefix is `us6`.

All API requests use the format:

```
https://{server_prefix}.api.mailchimp.com/3.0/
```
