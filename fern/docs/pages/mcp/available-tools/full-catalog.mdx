title: Full catalog
description: The 126 tools available on request from the Mailchimp MCP server, summarized by family.
---

The full catalog has 126 tools in 13 families, covering every Marketing API
operation the server serves beyond the core catalog. It's available on
request. Two of its tools need the Send permission: the ones that pause and
resume an RSS campaign.

A tool whose name ends in a specific record, such as a single contact or a
single report row, returns one record. A list tool returns one page of
results.
