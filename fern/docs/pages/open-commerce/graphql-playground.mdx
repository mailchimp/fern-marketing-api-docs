# GraphQL Playground

Explore and test the Mailchimp Open Commerce GraphQL API interactively.

## Access the Playground

When running Open Commerce locally, the GraphQL Playground is available at:

```
http://localhost:3000/graphql
```

## Example Query

```graphql
query {
  primaryShop {
    _id
    name
    description
  }
}
```

## Schema Explorer

Use the **Docs** panel in the Playground to browse the full schema, including all available queries, mutations, and types.
