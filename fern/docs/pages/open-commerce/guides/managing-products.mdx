# Managing Products

Use the Open Commerce GraphQL API to create and manage your product catalog.

## Create a Product

Use the `createProduct` mutation to add a new product to your catalog.

## Add Variants

Products can have multiple variants (size, color, etc.) created with the `createProductVariant` mutation.

## Publish a Product

Products must be published before they are visible in storefronts using the `publishProductsToCatalog` mutation.
