# Creating a Storefront

Open Commerce is headless, so your storefront is a separate application that communicates with the Open Commerce GraphQL API.

## Example Storefront

The open source [Example Storefront](https://github.com/reactioncommerce/example-storefront) is a Next.js app pre-wired to work with Open Commerce out of the box.

## Custom Storefront

Build your own storefront with any framework that can make GraphQL requests.
