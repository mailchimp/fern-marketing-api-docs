# Overview

Mailchimp Open Commerce is built on a plugin-based architecture. Every feature is a plugin, and you can add, remove, or replace any of them.

## Core Principles

- **API-first** — All functionality is exposed through a GraphQL API
- **Headless** — The frontend is completely decoupled from the backend
- **Modular** — Build only what you need with a plugin system
- **Open source** — Full access to the source code
