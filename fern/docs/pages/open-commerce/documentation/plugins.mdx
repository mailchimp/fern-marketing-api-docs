# Plugins

Open Commerce's plugin system lets you extend or replace any part of the platform.

## Official Plugins

| Plugin | Description |
|--------|-------------|
| `@reactioncommerce/plugin-payments-stripe` | Stripe payment processing |
| `@reactioncommerce/plugin-shippo` | Shippo shipping rates |
| `@reactioncommerce/plugin-taxes-avalara` | Avalara tax calculation |

## Custom Plugins

Create your own plugin by implementing the `registerPlugin` API.
