# Catalog

The catalog is the public-facing product listing in Open Commerce. Products are published from the internal product system to the catalog.

## Query the Catalog

```graphql
query {
  catalogItems(shopIds: ["your-shop-id"]) {
    edges {
      node {
        ... on CatalogItemProduct {
          product {
            title
            slug
          }
        }
      }
    }
  }
}
```
