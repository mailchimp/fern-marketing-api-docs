# Cart and Checkout

Open Commerce provides a full cart and checkout flow via GraphQL mutations.

## Create an Anonymous Cart

```graphql
mutation {
  createCart(input: { shopId: "your-shop-id", items: [] }) {
    cart {
      _id
    }
    token
  }
}
```

## Place an Order

Use the `placeOrder` mutation after collecting shipping and payment information.
