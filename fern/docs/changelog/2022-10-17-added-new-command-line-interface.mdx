---
title: Added new command line interface
tags: ["Open Commerce"]
---

We’ve written a new CLI so you can start developing your Open Commerce projects more easily. Now, you only need a simple command to create your project, create a custom plugin, or add the Open Commerce admin and storefront to the project. Check out all the commands at the  [CLI ReadMe](https://github.com/reactioncommerce/cli/blob/trunk/README.md) or by running `reaction help` in your terminal. Or, see our [guides and documentation](https://mailchimp.com/developer/open-commerce/) for more details. 

Getting started or completing routine workflows with Open Commerce had become slow and cumbersome due to excessive memory use and device slowdowns. With the new CLI, you can run the API, storefront and admin applications independently, which frees up memory and improves performance.
