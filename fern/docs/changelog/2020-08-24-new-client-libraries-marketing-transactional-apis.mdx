---
title: New client libraries for Marketing and Transactional APIs
tags: ["Transactional", "Marketing API"]
---

We have released [API client libraries](/tools) for the Marketing and Transactional APIs, supporting PHP, Node.js, Ruby, and Python.

We wanted to make it easier for developers to integrate their applications with both of our APIs in the language of their choice. The new libraries are generated from [publicly available API specs](https://github.com/mailchimp/mailchimp-client-lib-codegen) and published on the respective package managers for each supported language.
