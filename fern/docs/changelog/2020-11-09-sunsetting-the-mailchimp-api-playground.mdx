---
title: Sunsetting the Mailchimp API Playground
tags: ["Marketing API"]
---

We shut down the [Mailchimp API Playground](https://api.mailchimp.com/playground). 

The API Playground let users explore the Marketing API and the data it returns. Instead, we recommend users learn about and explore their API data with our new [API Reference docs](/marketing/api), which include rich code snippets written for our official [client libraries](/marketing/build/start-developing/send-your-first-api-request#install-a-client-library).
