---
title: Mobile SDK for iOS adds Swift Package Support
tags: ["Marketing API"]
---

We published a [Mailchimp Mobile SDK Swift package](https://github.com/mailchimp/Mailchimp-SDK-iOS/tree/master/.swiftpm/xcode) for use in Xcode. 

In Xcode 11 or newer, Swift Package Manager provides a native way to add package dependencies to Xcode. Compared to a third-party manager such as Cocoapods, Swift Package Manager is an even easier way to install the Mobile SDK. Making `MailchimpSDK` available as a Swift package allows us to reduce duplicate code and promote maintainability.
