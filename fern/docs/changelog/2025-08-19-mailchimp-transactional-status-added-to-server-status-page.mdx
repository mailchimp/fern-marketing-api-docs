---
title: Mailchimp Transactional status added to server status page
tags: ["Transactional"]
---

We've added live status tracking for Mailchimp Transactional API's servers to the [Mailchimp Server Status](https://status.mailchimp.com/) page. The page shows the current status and a history of recent service outages and their resolutions to help you troubleshoot your API calls and responses.

This lets you check the status of the Mailchimp Transactional servers quickly and easily, on the same page as our other servers.
