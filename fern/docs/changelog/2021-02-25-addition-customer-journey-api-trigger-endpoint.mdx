---
title: Addition of Customer Journey API trigger endpoint
tags: ["Marketing API"]
---

We added an endpoint similar to the [Add Subscriber to Workflow Email](/marketing/api/automations/create-email-queue) endpoint for the Customer Journey Builder. This is usable and dependent on the API 3.0 Starting Point/Wait.

This [Classic Automation trigger](https://mailchimp.com/help/all-the-classic-automation-triggers/) and [endpoint](/marketing/api/automations/create-email-queue) is valuable to our customers, but we can’t use the endpoint because it is located in the [Automations](/marketing/api/automations/list) section of the API. This new endpoint provides similar functionality, but it’s usable in the Customer Journey Builder, which provides new features and functionality not available in Classic Automations.
