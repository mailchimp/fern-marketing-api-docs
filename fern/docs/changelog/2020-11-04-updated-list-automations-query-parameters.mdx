title: Updated list automations query parameters
tags: ["Marketing API"]
---

We fixed a mistake in the [query parameters for filtering a list of automations](https://mailchimp.com/developer/api/marketing/automation/list-automations/). 

The query parameter filters were incorrectly documented as `before_send_time` and `since_send_time`. The correct parameters are `before_start_time` and `since_start_time`.
